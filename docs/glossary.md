# Mildcrowd developer glossary – Android

What the words in Mildcrowd' code, UI and docs mean: the German product words, membership and payments, the encrypted chat, moderation and law, shared technical terms, and in section 6 the terms of the Android app. The complete version, with the web and the other app's sections, is `docs/oasis-glossary.md` in the Laravel repo.

- **German product words stay German** in UI texts, code comments and docs – Tropfen, Quelle, Oase, Karawane, Mäzen, Zeitkapsel, Jahrbuch, Weitertragen … – and are never translated („drop“, „source“, „caravan“). Type and API names are English (`Post`, `Oasis`, `Follow`); the tables map one to the other.
- **The member-facing explanations live in `app/Support/Network/Glossary.php`** in the Laravel repo (tap-to-explain words, page `/app/begriffe`). The app's German texts must use the same words with the same meanings; when a meaning changes, change the member text, the Laravel glossary and the app texts together.
- **The code wins.** Where docs, comments or UI texts say something else, the entry names the difference. The web is the reference implementation (see „Web counterpart“).
- **Legal citations:** „Art.“ is an article of an EU regulation – always say which one, because DSA and DSGVO numbers collide (see „Art. 17 / 18 / 20“) –, „§“ a paragraph of a German statute; Abs., lit. and S. are explained in section 4.
- **Where** lists the main files. Paths without a label are in the Laravel repo (`oasis`); **iOS** paths are in `oasis-ios`, relative to `Packages/OasisKit/Sources/` unless they start with `App/`, `Config/`, `NotificationService/`, `ShareExtension/`, `UITests/`, `Packages/` or `project.yml`; **Android** paths are in `oasis-android`, where `…` stands for `src/main/kotlin/de/velwebsolutions/oasis`.
